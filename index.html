Flavor-HuHoBot

把 Discord 变成 Minecraft 服务器的管理面板。双向聊天、账号绑定、白名单联动、 AI Agent、MOTD 查询和本地 WebUI，全部集成在一个插件里。

下载插件 GitHub 仓库 Modrinth

功能

一个插件，覆盖聊天与管理
↔

双向聊天

游戏与 Discord 两个方向可使用不同频道；未填写频道 ID 的方向自动关闭。

⌁

账号绑定

一个 Discord 账号可绑定多个 Minecraft 账号，支持强制绑定、解绑和账号锁定。

✦

AI Agent

用自然语言查日志、执行命令、管理白名单与 Discord 成员，危险操作需要管理员审批。

▣

WebUI & MOTD

本地 WebUI 管理配置与审计；支持查询任意 Minecraft 服务器的 MOTD。
